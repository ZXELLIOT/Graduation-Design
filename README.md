# 毕业设计：基于 SimCSE 的检索式中文对话系统 (Retrieval-based Chinese Dialogue System)

> **时间戳 (最后更新):** 2026年3月30日
> **项目性质:** 本科毕业设计 (源代码与附件说明文档)

---

## 1. 项目概况
本项目为本科毕业设计成果，旨在构建一个相对完整、基于预训练模型的检索式中文对话系统。系统不采用复杂的生成式大模型路线，而是紧密结合**毕业设计任务书**的要求，聚焦于**对比学习（Contrastive Learning）与 SimCSE 预训练模型**的底层特征表示原理。通过计算语义相似度的方式，在特定中文字符闭环语料下完成对话意图计算与匹配输出，充分展示了 NLP 技术中表示学习与检索问答（QA）的结合能力。

## 2. 系统结构逻辑
本系统的运行逻辑遵循了任务书所拟定的“语料清洗 -> 句向量化 -> 相似度计算 -> 交互输出”的基础 NLP 对话开发流水线。在系统使用阶段，串行与集成执行流程如下：

1. **语料数据清洗预处理 [1/4]**：在系统冷启动时调用 `TextPreprocessor` 模块，读取 `data/raw_dialogues.txt` 进行文本清洗、去噪等格式化操作，为后续模块提供标准化的 `corpus.csv` 格式。
2. **加载结构化语料字典 [2/4]**：通过 `DataLoader` 将清洗后的标准文本对载入内存待命。
3. **构建 SimCSE 向量特征矩阵 [3/4]**：载入预训练的 SimCSE 构建器（`SimCSEEncoder`），建立针对该交互场景语料的密集词嵌入（Dense Embeddings）表示空间。
4. **意图匹配与前端交互系统 [4/4]**：利用 Gradio 构建便于测试验证的可视化交互 UI。捕获用户输入内容并向量投影后，在特征矩阵高维空间内通过**余弦相似度（Cosine Similarity）**进行比对（由 `DialogMatcher` 负责），检索并返回相似度得分最佳的预设答复。

## 3. 核心部件与《任务书》映射情况
项目的源代码结构主要集中在 [Graduation-Design/system](system/) 目录下，各模块职责相互解耦，代码逻辑设计严格对标了毕业论文《任务书》中的具体任务：

* **`system/src/preprocess.py` (语料预处理模块)**
  * **对应的任务书要求**：“设计并实现中文对话语料的预处理流程，包括文本清洗、分句与去噪等操作”。
  * **代码实现说明**：负责对 `data` 目录下的非结构化闲聊/任务文本集进行杂质过滤、切词降噪等前置工程步骤。
* **`system/src/model.py` (向量编码模型模块)**
  * **对应的任务书要求**：“基于预训练的中文 SimCSE 模型，将用户输入语句转换为语义向量表示” / “学习对比学习原理”。
  * **代码实现说明**：该部件是本项目核心算法所在。封装了 SimCSE 结构对中文自然语言的深度特征抽取接口，使用户查询能够进行高质量的空间映射计算，突破简单的字符重合限制。
* **`system/src/matcher.py` (对话检索与匹配评价模块)**
  * **对应的任务书要求**：“基于 SimCSE 句向量相似度计算，实现用户输入与候选回复之间的匹配机制结合检索式方法，完成选择与输出”。
  * **代码实现说明**：针对用户新产生的输入进行推断操作，利用数学分析查找欧氏/余弦距离层面的极值，获取匹配准确度，进行候选回复裁定反馈。
* **`system/app.py` (对话实验 UI 测试与系统总入口)**
  * **对应的任务书要求**：“使用 Python 构建完整的中文对话系统流程，集成语义编码、相似度计算与回复模块；通过示例对话和简单评价指标对系统效果进行测试与分析”。
  * **代码实现说明**：担任系统总线集成控制器，利用第三方轻量级展示架构搭建评价实验环境，通过后台打点和系统诊断日志输出诊断指标与置信度得分，为撰写毕业论文“实验与结果分析”部分提供数据和截图支撑点。

## 4. 运行配置与测试演示说明
（开发提示：运行源码前需确保系统已安装 Python 等基础环境。）

```bash
# 1. 切换至系统代码根目录
cd system

# 2. 安装 NLP 与后端所需运行依赖项
pip install -r requirements.txt

# 3. 启动并测试对话系统主程序
python app.py
```
*启动日志运行结束时，可通过系统返回的 Web 端口（如 `http://127.0.0.1:7860`）通过浏览器登入对话平台并执行验收对话测验。*
