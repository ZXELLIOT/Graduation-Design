# 毕业设计：基于 SimCSE 的检索式中文对话系统

> **(最后更新):** 2026年4月3日
> **项目性质:** 本科毕业设计 (源代码与附件说明文档)

---

## 1. 项目概况
本项目为本科毕业设计成果，旨在构建一个相对完整、基于预训练模型的检索式中文对话系统。系统不采用复杂的生成式大模型路线，，聚焦于**对比学习（Contrastive Learning）与 SimCSE 预训练模型**的底层特征表示原理。通过计算语义相似度的方式，在特定中文字符闭环语料下完成对话意图计算与匹配输出。

## 2. 系统结构逻辑
本系统的运行：语料清洗，句向量化，相似度计算，交互输出。在系统使用阶段，集成执行流程如下：

1. **语料数据清洗预处理 [1/4]**：在系统启动时调用 `TextPreprocessor` 模块，读取 `data/raw_dialogues.txt` 进行文本清洗、去噪等格式化操作，为后续模块提供标准化的 `corpus.csv` 格式。
2. **加载结构化语料 [2/4]**：通过 `DataLoader` 将清洗后的标准文本对载入内存待命。
3. **构建 SimCSE 向量特征矩阵 [3/4]**：载入预训练的 SimCSE （`SimCSEEncoder`）。
4. **意图匹配与前端交互系统 [4/4]**：利用 Gradio 构建可视化交互 UI。捕获用户输入内容后，在特征矩阵内通过**余弦相似度（Cosine Similarity）**进行比对（由 `DialogMatcher` 负责），检索并返回相似度得分最佳的预设答复。
